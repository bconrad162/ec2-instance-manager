Project plan: EC2+SSM Instance Explorer (Tauri, profileChoice-only, Windows + Pop!_OS)
Goal

Desktop GUI that:

Uses ~/.aws/profileChoice as the only AWS profile selector (read-only)

Shows active AWS Profile / Account / Region prominently

Lists EC2 instances and supports fast filtering by tags/search

Indicates which instances are SSM-managed and online/offline

Opens local terminal sessions via SSM (aws ssm start-session) using the detected terminals on the host

Shows credential status (OK/Expired/Missing) but does not refresh credentials

Non-goals

No in-app login/credential refresh (you run saml2aws yourself)

No AWS console/browser Session Manager

No writing/modifying ~/.aws/profileChoice

No AWS CI/CD services

Target platforms

Windows 11

Pop!_OS 24.04 (COSMIC)

Core workflow

App reads ~/.aws/profileChoice → sets active profile.

App calls STS GetCallerIdentity to show account + auth status.

App fetches EC2 inventory and joins with SSM managed instances.

User filters/searches and selects an instance.

User clicks Connect → app opens a terminal on the local machine and runs:

aws ssm start-session --target <instance-id> --region <region>

with AWS_PROFILE=<profileChoice> in the spawned environment

Terminal launching (dynamic discovery + user-selectable default)
Requirement

App detects terminals available on the host OS at runtime and presents them in Settings. User selects a default; app persists it. Always provide a “Custom template” fallback.

Windows terminal discovery (probe PATH + known locations)

Detect and expose:

PowerShell 7: pwsh.exe (preferred)

Windows PowerShell: powershell.exe

Windows Terminal: wt.exe

Git Bash: bash.exe (PATH and common Git install dirs)

CMD: cmd.exe

WSL: wsl.exe (optionally enumerate distros via wsl -l -q)

Default on Windows: PowerShell (pwsh if available, else powershell.exe)

Pop!_OS terminal discovery (probe PATH)

Detect and expose:

COSMIC terminal (probe likely names such as cosmic-term, cosmic-terminal)

gnome-terminal

kitty

alacritty

konsole

xterm

Default on Pop!_OS: COSMIC terminal if found, else next available (gnome-terminal etc.)

Launch adapters (normalize “run command in terminal”)

Create an internal adapter per terminal type to open a terminal and run a command, keeping it open:

PowerShell: -NoExit -Command "<cmd>"

CMD: /k <cmd>

Windows Terminal: open new tab/window with configured profile + run shell command

Git Bash: bash -lc '<cmd>'

WSL: wsl -d <distro> -- bash -lc '<cmd>'

Linux terminals: terminal-specific “execute command” flags normalized in adapters

STS GetCallerIdentity

Acceptance criteria (high-level)

Always shows active AWS profile from ~/.aws/profileChoice on top bar.

Switching profile via your CLI updates the GUI automatically within seconds.

Filtering by tags/search is fast and does not require AWS calls.

“Connect” opens the chosen terminal and starts an interactive SSM session without browser usage.

Works on Windows and Pop!_OS, dynamically listing terminals available on each system.

Clear “Expired creds” state when saml2aws session expires; user refreshes externally.
